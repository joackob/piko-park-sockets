# AGENTS.md - Piko Park Juego

This is an Astro + TypeScript project using Bun as the package manager. It simulates a physics playground using Matter.js.

## Build / Run Commands

```bash
bun install        # Install dependencies
bun dev            # Start dev server at localhost:4321
bun build          # Build for production
bun preview        # Preview production build locally
bun astro check    # Run Astro type checking
```

## Code Style Guidelines

### TypeScript Conventions

- **Strict mode enabled** - All null checks must be explicit (`strictNullChecks: true` in tsconfig.json)
- **Use interfaces** for object shapes, especially for constructor parameters and component props
- **Prefer explicit typing** on function parameters and return types, especially for public APIs
- **Use type inference** for local variables where the type is obvious from initialization

### Naming Conventions

The codebase uses **Spanish naming** for identifiers (mixing English and Spanish):

```typescript
// Classes: PascalCase (Spanish)
class MotorFisico { }
interface PropiedadesDelMotorFisico { }

// Functions: camelCase (Spanish verbs)
crearUnCirculo()
crearMarco(lienzo: HTMLCanvasElement)

// Variables: camelCase (Spanish)
const limitesDelLienzo
const grosorDeLosLimites

// Constants: camelCase with descriptive names
const atomicTangerineColor = "#fd9678ff";
```

### Imports

- Use **path aliases** defined in tsconfig.json:
  ```
  @motor/*     → src/motor/*
  @cuerpos/*   → src/cuerpos/*
  @colores/*   → src/colores/*
  @layouts/*   → src/layouts/*
  @components/* → src/components/*
  ```

- Use **named exports** (avoid default exports for utilities)

### Formatting

- 2 spaces for indentation
- No semicolons at end of statements
- Use single quotes for strings
- Trailing commas in multiline structures
- Arrow functions for short callbacks; regular functions for methods

### Error Handling

- Use explicit type guards when checking for null/undefined
- Wrap potentially failing operations in try-catch only when side effects need handling
- Let TypeScript errors surface at build time rather than suppressing with `as`

### Astro Components

- Frontmatter imports at top of `.astro` files
- Use `client:load` or `client:visible` for interactive components
- Target elements with data attributes when multiple instances exist: `canvas[piko-park-canvas]`

### File Organization

```
src/
├── cuerpos/      # Matter.js body factories (crearUnCirculo, crearMarco, etc.)
├── colores/      # Color constants
├── motor/        # Engine wrapper class (MotorFisico)
├── layouts/      # Astro layouts
├── components/   # Astro components
└── pages/        # Astro pages
```

## TypeScript Configuration

The project extends `astro/tsconfigs/strict`. Key settings:
- `strictNullChecks: true`
- `baseUrl: .`
- Path aliases for all `src/` subdirectories
